Google Apps Script Webhook Setup

  1. Visit script.google.com and click New Project.
  2. Click the button below to copy the ChurchTech Google Apps Script code to your clipboard.
  3. Paste the code into the script editor, replacing any default template code.
  4. Click Deploy → New deployment.
  5. Select type: Web app. Set Execute as: Me and Who has access: Anyone.
  6. Click Deploy, authorize Google permissions, and copy the generated Web App URL.
  7. Paste that Web App URL into ChurchTech Settings above and click Test Webhook Connection!
