☁️ Google Drive Sync Settings

ChurchTech uploads your brain dumps directly to your Google Drive as numbered Google Docs using a free, lightweight Google Apps Script Web App.

The URL generated when deploying your Google Apps Script as a Web App (set to "Execute as: Me" and "Who has access: Anyone").

Open your Google Drive folder in a browser and copy the string of characters after /folders/ in the URL. If left empty, notes will be saved into a folder named "ChurchTech Brain Dumps".

📋 Google Apps Script Webhook Setup

Follow these 5 quick steps to deploy your Google Drive webhook:

  1. Visit script.google.com and click + New project.
  2. Click the button below to copy the complete ChurchTech Brain Dump Webhook script.
  3. In the Apps Script editor, replace all existing code in Code.gs with the copied script and press Ctrl+S (or Cmd+S) to save.
  4. Click Deploy → New deployment. Click the gear icon next to "Select type" and choose Web app.
  5. Set Execute as: Me and Who has access: Anyone. Click Deploy, authorize permissions, copy the Web App URL, and paste it into the field above!
💡 Automatic Note Numbering:

When you upload a note (e.g. "BT Business Router"), the script automatically scans your target folder, finds existing docs with that title, and assigns the next incremented number (- note 001, - note 002). Existing documents are never overwritten.
